# task-005 — Define authority-ceiling and effective-authority schemas

**Status:** APPROVED FOR EXECUTION
**Dependencies:** task-003, task-004

## Objective
Model declarative authority ceilings and effective authority as deterministic actions/resources/tenants/scopes/purpose/audience/time constraints.

## Acceptance
Authority contains no executable policy language; subset/ceiling semantics are canonicalizable; credential capability is not treated as authority.
