# Governance

DARE Agent Security is currently a DARE Labs-led open-source project.

## Current model

During the pre-alpha phase, maintainers appointed by DARE Labs are responsible for:

- release decisions;
- security-sensitive changes;
- standards mappings;
- acceptance of new active-testing capabilities;
- repository administration;
- compatibility and safety policy.

Community contributions are welcome through pull requests and issues.

## Decision principles

Project decisions should prioritize:

1. security and safe defaults;
2. reproducibility;
3. standards interoperability;
4. evidence-backed findings;
5. backwards-compatible evolution where practical;
6. a clear boundary between open-source community functionality and private customer/commercial technology.

## Standards neutrality

DARE Agent Security may implement tests and mappings for multiple standards and vendors. The project should avoid becoming technically dependent on a single identity provider, LLM vendor, MCP implementation, policy engine, or cloud provider.

## Maintainers and contributors

The maintainer model will evolve if the project develops a sustained external contributor community. Future governance may define maintainers by subsystem and documented promotion/removal criteria.

## Commercial boundary

Governance of this repository applies only to the Apache-2.0 code and assets intentionally published here. It does not govern proprietary DARE Labs or Dewtech products, customer-specific code, private datasets, private findings, or commercial services.
