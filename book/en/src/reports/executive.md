# Executive Report

`reports/executive.html`, generated by `assess` and `report`, is written for
someone deciding whether to act — not for someone debugging the tool.

## What it contains

- Overall gate verdict (PASS / FAIL / PARTIAL / BLOCKED / INCONCLUSIVE).
- Assessment Coverage summary — what was actually checked, in plain terms.
- Findings, ranked, with plain-language explanations of impact.
- Classification metadata (e.g. `CONFIDENTIAL`) when running in
  [Confidential Mode](../privacy/confidential-mode.md).

## What it deliberately leaves out

Full request/response traces and raw evidence payloads — those belong in the
[Technical Report](technical.md), so the executive report stays readable in
one pass.

## Regenerating it

```bash
dare-agent-security report --refresh
```

`--refresh` re-renders HTML from the stored `summary.json`/`findings.json`
without re-running the assessment.
